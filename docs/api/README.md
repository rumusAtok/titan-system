# API specifications

Generated by `npm run openapi:export` from the running services. Do not edit by hand.

All routes are reached through the API gateway as `/api/<key>/<path>` and require a bearer token
issued by Keycloak. Every service also serves its interactive documentation at `/api/<key>/docs`.

Errors use one shape: `{ "error": { "status", "code", "message", "details?", "correlation_id" } }`.
